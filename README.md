# Trimmage

Trimmageは、Windowsで画像を手軽にトリミングできるツールです。エクスプローラーで画像を右クリックして開き、範囲や角度を調整して保存できます。元画像はそのまま残ります。

## 主な機能

- **トリミング**：ドラッグで範囲を選択。1:1、4:3、16:9などの比率固定や自由な切り抜きに対応
- **回転・反転**：90°回転、左右・上下反転に加え、0.1°単位で角度を微調整
- **サイズ指定**：保存する幅と高さを指定。比率を固定したまま変更可能
- **用途別プリセット**：Xのヘッダー、YouTubeのバナー、Discord、Instagramなどのサイズを選択可能
- **ガイド表示**：SNSアイコンの円形プレビューや、一部プリセットのセーフエリアを表示
- **マウス操作**：ホイールで拡大・縮小、中ボタンドラッグで表示位置を移動

## インストール

配布形式はインストーラー版とポータブル版の2種類です。

- **インストーラー版**：セットアップファイル（`*_Setup.exe`）を実行します。
- **ポータブル版**：ZIPを任意の場所に展開し、`Trimmage.exe`を一度起動します。

初回のセットアップ時に、画像の右クリックメニューへの登録とWindows起動時の自動起動が設定されます。どちらもタスクトレイから変更できます。

.NETの追加インストールは不要です。

## 使い方

1. エクスプローラーで画像を右クリックし、**「画像をトリミング」**を選びます。
2. トリミング枠、角度、縦横比、保存サイズなどを調整します。
3. **「コピーを保存」**を押すと、元画像と同じフォルダーに編集後の画像が保存されます。

保存名は `photo_trim.jpg` のようになります。同名のファイルがある場合は `photo_trim(2).jpg` のように連番が付き、元画像は上書きされません。

元の形式で書き出せない場合はPNG形式で保存されます。読み込める画像形式は、Windowsにインストールされている画像コーデックによって異なります。

## 右クリックメニューと常駐設定

Windows 11では、通常 **「その他のオプションを確認」**の中に「画像をトリミング」が表示されます。

タスクトレイのTrimmageアイコンを右クリックすると、次の設定を変更できます。

- 画像の右クリックメニューへの登録
- Windows起動時の自動起動
- 従来の右クリックメニューへの切り替え

「従来の右クリックメニューを使う」を切り替えると、Windows全体の右クリックメニューの表示方式が変わります。反映時にはエクスプローラーが再起動し、開いているフォルダーが一度閉じられるため、ファイル操作中の変更は避けてください。

なお、トレイから通常の「終了」を選んでも、登録済みの右クリックメニューは引き続き使えます。

## アンインストール

- **インストーラー版**：Windowsの「インストールされているアプリ」からアンインストールします。
- **ポータブル版**：トレイメニューの **「右クリック登録と自動起動を解除して終了」**を選んでから、展開先のフォルダーを削除します。

## 動作環境

Windows向け（配布版は64bit）です。
